# Skills Folder

Store all reusable skill documents in this folder.

## Conventions
- One skill per Markdown file.
- Use clear names, for example: `step_result_unify_skill.md`.
- Keep skills focused and executable (rules, examples, constraints).

## Current Skill
- `step_result_unify_skill.md`: Used to standardize `step` and `expected_result` text from parsed TestRail JSON.
- `kb_semantic_alignment_skill.md`: Semantic KB generation standard from cleaned/auto_cases input with monotonic semantic alignment and quality gates.
- `kb_to_dsl_semantic_skill.md`: Semantic KB to DSL mapping standard with intent mapping, row stability, and fallback ratio checks.
- `dsl_to_action_schema_skill.md`: DSL to executable action schema mapping standard with deterministic operation/assertion mappings.
